### Question

How is an engine failure in cruise different from one on takeoff?

### Answer

Better in every way that matters, which is why it's the phase used for training.

- You have **altitude and airspeed**, so there is time to work methodically rather than reflexively.
- You are already clean, so the drag reduction step is mostly just feathering.
- You can trade altitude for time while you run the checklist.

The process is the same - control, configure, identify, verify, feather, secure - but done deliberately and backed up with the printed checklist.

The new problem is **where to go**. Expect to drift down to the single-engine service ceiling, so pick an airport you can reach from a descending profile, consider terrain, and start the diversion early rather than troubleshooting for ten minutes first.
